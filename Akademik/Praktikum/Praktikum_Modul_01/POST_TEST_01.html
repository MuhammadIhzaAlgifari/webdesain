2. Teknik Informatika

Profil Program Studi

Program studi Teknik Informatika mempelajari ilmu komputer, pemrograman, algoritma, pengembangan perangkat lunak, jaringan komputer, dan kecerdasan buatan.

Profil Lulusan dan Pilihan Karier

  • Software Developer
  • Programmer
  • Web Developer
  • Network Engineer
  • AI Developer

Kegiatan dan Pengembangan Kompetensi

  • Magang di bidang teknologi informasi
  • Proyek pengembangan perangkat lunak
  • Pelatihan pemrograman dan jaringan komputer

3. Desain Komunikasi Visual

Profil Program Studi

Program studi Desain Komunikasi Visual mempelajari penyampaian pesan melalui elemen visual, seperti ilustrasi, tipografi, fotografi, desain grafis, branding, dan media digital.

Profil Lulusan dan Pilihan Karier

  • Graphic Designer
  • UI/UX Designer
  • Illustrator
  • Art Director
  • Motion Graphic Designer

Kegiatan dan Pengembangan Kompetensi

  • Pameran karya desain
  • Proyek desain komunikasi visual
  • Magang di industri kreatif

4. Teknik Sipil

Profil Program Studi

Program studi Teknik Sipil mempelajari perencanaan, perancangan, pembangunan, dan pemeliharaan infrastruktur, seperti gedung, jalan, jembatan, serta sistem pengairan.

Profil Lulusan dan Pilihan Karier

  • Site Engineer
  • Structural Engineer
  • Project Engineer
  • Quantity Surveyor
  • Konsultan Konstruksi

Kegiatan dan Pengembangan Kompetensi

  • Praktik perencanaan konstruksi
  • Studi lapangan
  • Magang di bidang konstruksi

5. Manajemen Informatika

Profil Program Studi

Program studi Manajemen Informatika mempelajari pemanfaatan teknologi informasi untuk mendukung pengelolaan data, administrasi, sistem informasi, dan kebutuhan operasional organisasi.

Profil Lulusan dan Pilihan Karier

  • Web Programmer
  • Database Administrator
  • IT Support
  • System Administrator
  • Junior System Analyst

Kegiatan dan Pengembangan Kompetensi

  • Praktik pembuatan aplikasi
  • Pengelolaan basis data
  • Magang di bidang teknologi informasi
